# tela

Text Extraction & Local Archiving abbreviato in TELA è un ecosistema self-hosted progettato per colmare il divario tra gli appunti analogici e l'archiviazione digitale. Nasce per gestire il flusso di lavoro da un tablet Huion Note X10 verso un Raspberry Pi 5, trasformando la scrittura a mano in testo ricercabile.
